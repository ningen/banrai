# ADR-0003: カレンダー UI — 人×時間グリッド

Status: Accepted (2026-08-27)

## Context

- 現場当日のオペレーションが主用途: 誰が何時にどこへ行くか
- 方向性検討 (9案の壁打ち) の結果、週単位カレンダー (案1) を試した後、
  現場系の王道である「人×時間」(案3) を採用

## Decision

- ホーム画面は `DaySchedule`: 列 = スタッフ (+ 未割当列)、行 = 時刻 (6:00–21:00, 48px/hr)
- 作業ブロックは開始/所要時間ぶんの高さで配置、重なりはレーン分割
- 30 分マスをクリック → そのスタッフ・時刻で作業新規作成 (担当/時刻プリセット)
- 今日のみ現在時刻ラインを JST で表示
- 作業詳細は right Sheet (JobDrawer) で同上 — 該当機能は ADR-0004 参照

## Consequences

- 週俯瞰は「作業一覧 (カンバン)」が担う (日毎の粒度は DaySchedule)
- スタッフが多数になると幅が広くなる → 横スクロール + min-width で対応
